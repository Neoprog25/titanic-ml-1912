# 🚢 R.M.S. Titanic — 1912 Cinematic Machine Learning Experience

Ushbu loyiha Titanic yo'lovchilarining omon qolish ehtimolini hisoblovchi to'liq Machine Learning quvuri (Pipeline), GridSearchCV optimizatsiyasi hamda 1912-yilgi "White Star Line" estetikasiga ega kinematik veb-ilovadir (Flask + Video-First Responsive UI).

## 🌟 Asosiy Xususiyatlar
- **Machine Learning Quvuri:** Scikit-Learn `ColumnTransformer` va `RandomForestClassifier` orqali to'liq avtomatlashtirilgan ma'lumotlarni qayta ishlash.
- **Kinematografik Video Fonlar:** Foydalanuvchining harakatlariga (jinsi, yoshi, sayohat klassi, oilaviy holati, chiqish porti) qarab silliq (cross-fade) almashuvchi 15+ ta tarixiy video manzaralar.
- **Suzuvchi Yon Panel (Floating Sidebar):** Ekranning 75% qismini ochiq qoldiruvchi zamonaviy multi-step wizard.
- **Taqdir Muhri:** 1912-yilgi vintage pochta shtampi animatsiyasi (`SURVIVED` yoki `LOST AT SEA`).
- **Serverless Deploy:** Vercel platformasi uchun to'liq optimallashtirilgan arxitektura.

## 🚀 Mahalliy Ishga Tushirish
```bash
pip install -r requirements.txt
python train_model.py
python app.py
```
Brauzerda `http://127.0.0.1:5000` manzilini oching.
